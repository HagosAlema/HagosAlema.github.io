Technical Highlights & Architecture

Uniwaffle eliminates single points of failure in private key management by replacing raw seed phrases with threshold cryptographic key splitting.

Native C++ MPC Key Splitting

Engineered high-speed C++ cryptographic algorithm implementing Shamir's Secret Sharing (t-of-n threshold) integrated directly into Kotlin using Android NDK and JNI.

C++17 JNI NDK

USB Hardware Cold Storage

Developed OTG USB hardware communication layer using libusb to write encrypted secret key shares onto physical USB tokens for offline cold recovery.

libusb Android OTG Cold Storage

Biometric & Face Auth

Integrated Dlib computer vision for biometric face verification alongside Android Keystore hardware-backed encryption prior to signing key assembly.

Dlib Android Keystore Biometrics

Multi-Chain Transaction Engine

Integrated Trust Wallet Core SDK for cross-chain transaction formatting, support for ERC-20, SPL tokens, EVM networks, and Solana blockchains.
